# ImpulsaTlapa

Plataforma web responsive para fortalecer el comercio local de Tlapa de Comonfort.

## Módulos
- Registro e inicio de sesión con correo y contraseña.
- Catálogo de productos con nombre, precio, descripción, categoría e imagen.
- Búsqueda simple por palabra clave y categoría.
- Contacto directo por WhatsApp.
- Panel básico de administración.

## Instalación
1. Instalar Node.js y MySQL.
2. Crear la base de datos ejecutando `sql/database.sql`.
3. Copiar `.env.example` como `.env` y colocar los datos de MySQL.
4. Ejecutar:

```bash
npm install
npm start
```

5. Abrir: http://localhost:3000
